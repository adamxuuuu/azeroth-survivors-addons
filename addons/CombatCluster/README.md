# Combat Cluster / 伤害聚合

适用于 Azeroth Survivors 浏览器客户端的 WoW 1.12 addon。按技能／伤害来源聚合自己造成的伤害，在屏幕右侧中部固定排列（距右边缘约 20% 屏幕宽度），避免后期大量数字遮挡战场。

- 每约 0.75 秒结算一组数字，同一来源的伤害相加。
- 按本窗口伤害从高到低排列；最多 7 个独立来源，多余来源合并为灰色“其他”。
- 每个来源具有稳定颜色，只显示图标和数字；颜色代表来源，不代表物理／火焰等学派。有限调色板可能复用颜色。
- 技能图标在数字左侧，边长跟随数字字体高度。不显示来源名称或标题。优先从客户端 AZS_TIMERS / AZS_PETS / AZS_DEBUFFS 数据按名称匹配图标，法术书作为补充；无法匹配的来源和“其他”合计使用问号图标。
- 大数字用 K / M 缩写；约 1 秒后淡出，2 秒无新结算后隐藏。
- 使用 AZS_GetMeter 累计数据的差值，不解析本地化战斗日志，不逐次创建文字对象。每 0.2 秒读取一次，界面复用固定的 8 行。
- 中途启用会先记录基线，不把之前整局的伤害一次性刷出。

## 安装与使用

浏览器游戏中打开 **Options → AddOns → Install**，选择项目里的 `dist/CombatCluster.zip`，下次进入游戏世界时加载。

默认启用。聊天命令：

- `/ccluster off`：关闭面板，恢复插件启用前的原版伤害数字设置。
- `/ccluster on`：重新启用，接下来的伤害从新基线开始统计。

插件只修改 `CombatDamage`，不修改治疗、承受伤害提示或已有伤害统计面板。观察到死亡、胜利、退出本局或 PLAYER_LOGOUT 时恢复原设置。如果浏览器崩溃、强制关闭页面或在局中移除插件，可能来不及恢复；请在游戏选项里重新勾选 **Show Target Damage / 显示目标伤害**（CombatDamage）。

## 限制和验证

需要 AZS_GetPhase、AZS_GetMeter、AZS_GetRunTime，以及客户端支持的标准 Frame / FontString API。缺失伤害统计 API 时会提示一次，并保持原版数字。客户端是否实际响应 CombatDamage 开关需要在游戏内确认。

伤害来源来自游戏统计接口，可包含宠物、天赋或装备触发。不提供学派、命中次数或暴击细节。源数据若有延迟，数字也会延迟；K/M 是格式化近似值，底层增量不作缩放。界面使用游戏自带字体。

执行 `lua tests/combat-cluster.lua`（Lua 5.1）可检查聚合、排序、来源颜色稳定性、溢出合并、淡出、中途加载、跨局重置、暂停、开关、注销恢复和 API 缺失处理。此次已通过该模拟接口测试及 ZIP 完整性检查；未完成浏览器真实战斗、中文字体、分辨率或原版数字关闭的实测。
